# 🗺️ Master Execution Roadmap (แผนการลงมือเขียนโค้ด)

นี่คือลำดับขั้นตอนการทำงาน (To-Do List) 1-2-3-4 เพื่อเปลี่ยนจากเอกสารดีไซน์ ให้กลายเป็นระบบ ERP ที่ใช้งานได้จริง พร้อมจุดตรวจสอบ (Checkpoint) ในแต่ละเฟสครับ

---

## 🛠️ Phase 1: Setup Backend & Database (สร้างรากฐาน)
*   **[x] Step 1:** ติดตั้ง **.NET 8 SDK** และสร้างโปรเจกต์ `C# Web API`
*   **[x] Step 2:** ติดตั้ง Packages ที่จำเป็น (EF Core, Npgsql สำหรับ Postgres, JWT, FluentValidation)
*   **[x] Step 3:** สร้าง Class (Entities) ตาม ER Diagram (Products, Users, PO, SO)
*   **[x] Step 4:** เชื่อมต่อกับ Supabase และรันคำสั่ง Migration เพื่อสร้างตารางใน Database
*   🎯 **ตรวจสอบความถูกต้อง (Checkpoint 1):** 
    *   เปิดหน้าเว็บ Supabase ดูว่ามีตารางและคอลัมน์โผล่ขึ้นมาครบถ้วนตาม ER Diagram หรือไม่

## 🧠 Phase 2: Core APIs & Migration (สร้างสมองและย้ายข้อมูล)
*   **[x] Step 5:** ตั้งค่า Global Error Middleware และเปิดใช้งาน Swagger
*   **[x] Step 6:** เขียน API ระบบ Login พร้อมสร้าง JWT Cookie
*   **[x] Step 7:** (ข้าม) ไม่ย้ายข้อมูลจาก MongoDB เลือกล้างไพ่ทำสต๊อกใหม่ทั้งหมด
*   **[x] Step 8:** เขียน API จัดการสินค้า (CRUD)
*   🎯 **ตรวจสอบความถูกต้อง (Checkpoint 2):** 
    *   เปิดหน้าเว็บ Swagger
    *   ลองกด Login เพื่อรับ JWT
    *   ลองกดยิง API ดึงข้อมูลสินค้าว่ามีของเก่าจาก Mongo ติดมาถูกต้องหรือไม่

## 🎨 Phase 3: Setup Frontend (สร้างหน้าบ้าน)
*   **[ ] Step 9:** ติดตั้ง Angular CLI v18 (`npm install -g @angular/cli@18`) และสร้างโปรเจกต์ด้วย `ng new`
*   **[ ] Step 10:** ติดตั้งเครื่องมือตกแต่ง UI (เช่น Tailwind CSS หรือ Angular Material)
*   **[ ] Step 11:** สร้างไฟล์ Routing เตรียมโครงร่างหน้าจอต่างๆ ตาม Sitemap ที่ออกแบบไว้
*   **[ ] Step 12:** สร้าง HttpInterceptor เพื่อคอยดักเอา JWT แปะส่งไปให้ C# อัตโนมัติ

## 🖱️ Phase 4: UI Development (ประกอบร่างหน้าเว็บ)
*   **[ ] Step 13:** ทำหน้า Login และ Layout หลักสำหรับหลังบ้านพนักงาน (Admin Sidebar)
*   **[ ] Step 14:** ทำหน้าจัดการสินค้าของแอดมิน (ตารางรายชื่อ และฟอร์มเพิ่ม/แก้ไข พร้อมช่องกรอก JSON Specs)
*   **[ ] Step 15:** เชื่อม API การอัปโหลดรูปภาพผ่าน Cloudinary
*   **[ ] Step 16 (ใหม่):** ทำหน้าเว็บโซนลูกค้า Public Storefront (หน้าโฮมเพจ, แคตตาล็อกสินค้าคอมพิวเตอร์, และระบบตะกร้าสินค้า)
*   🎯 **ตรวจสอบความถูกต้อง (Checkpoint 3):** 
    *   ลูกค้าทั่วไปเปิดหน้าเว็บเข้ามาดูสินค้าคอมพิวเตอร์และสเปค กดปุ่มซื้อได้
    *   พนักงานเข้าเว็บ Angular พิมพ์ Login สำเร็จ
    *   แอดมินกดเข้าเมนูสินค้า, กดเพิ่มรูปภาพ, กรอกข้อมูล, กดบันทึก แล้วข้อมูลไปโผล่ในหน้าร้านให้ลูกค้าเห็นทันที

## ⚙️ Phase 5: ERP Business Logic (เขียนระบบบัญชี/สต๊อก)
*   **[ ] Step 17:** ทำเมนูและ API ของระบบจัดซื้อ (PO) -> **ไฮไลท์:** เขียน `try/catch` + Transaction รับของเข้าเพื่อ **+เพิ่มสต๊อก**
*   **[ ] Step 18:** ทำเมนูและ API ของระบบขาย (SO) -> **ไฮไลท์:** เขียน `try/catch` + Transaction เปิดบิลเพื่อ **-หักสต๊อก**
*   **[ ] Step 19:** ใส่ Role Guards ดักไม่ให้ฝ่ายขายเข้าหน้าจัดซื้อ
*   🎯 **ตรวจสอบความถูกต้อง (End-to-End Check):** 
    *   ล็อกอินเป็นฝ่ายจัดซื้อ -> เปิด PO 100 ชิ้น -> สต๊อกต้องเพิ่ม 100
    *   ล็อกอินเป็นฝ่ายขาย -> เปิดบิลขาย 2 ชิ้น -> สต๊อกต้องเหลือ 98
    *   (เช็คว่าจังหวะนี้ข้อมูลไม่พัง และถ้าเน็ตหลุดกลางคัน ข้อมูลต้อง Rollback คืนค่าเดิม)

🎉 **เสร็จสิ้นโปรเจกต์ ERP!** 🎉

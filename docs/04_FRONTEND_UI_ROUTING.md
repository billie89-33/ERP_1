# Frontend UI & Routing Structure (Angular)

## 🗺️ การเปลี่ยนหน้าใน Angular (Routing)
ใน Angular การทำหน้าเว็บหลายๆ หน้าและลิงก์หากัน เราจะใช้โมดูลที่ชื่อว่า **`Angular Router` (Routing)** ครับ 

จุดเด่นคือมันเป็น **Single Page Application (SPA)** หมายความว่าเวลาผู้ใช้กดลิงก์ หน้าเว็บจะไม่กระพริบ (ไม่ Reload โหลดใหม่ทั้งหมด) แต่มันจะแค่ดึง Component ของหน้าใหม่มาสลับแปะลงไปแทนหน้าเดิม ทำให้เว็บเร็วมากครับ

*   **โค้ดลิงก์หน้า HTML ทั่วไป:** `<a href="/products">สินค้า</a>` (เว็บจะกระพริบโหลดใหม่)
*   **โค้ดลิงก์ของ Angular:** `<a routerLink="/products">สินค้า</a>` (เว็บไม่กระพริบ เร็วมาก)

## 🎨 โครงสร้างหน้าจอ UI ทั้งหมด (Sitemap & Routes)
เพื่อให้ระบบ ERP ของเราครบถ้วนและเชื่อมโยงกัน นี่คือรายการหน้าจอทั้งหมดที่ต้องมี (จัดกลุ่มตาม Module ของ Angular):

### 1. 🔐 Auth Module (ระบบล็อกอิน)
*   `/login` 👉 หน้า Login สำหรับพนักงาน

### 2. 🏠 Core Layout (โครงสร้างหลัก)
เมื่อ Login เข้ามา จะเจอ **Layout หลัก** ที่แสดงอยู่ทุกหน้า:
*   **Sidebar (เมนูด้านข้าง):** สำหรับคลิกเปลี่ยนหน้า `routerLink` ไปเมนูต่างๆ
*   **Header (แถบบน):** แสดงชื่อผู้ใช้งาน และปุ่ม Logout

### 3. 📊 Dashboard Module
*   `/dashboard` 👉 หน้าแรกหลัง Login แสดงกราฟยอดขาย, จำนวนใบสั่งซื้อที่ค้างอยู่, และเตือนสินค้าใกล้หมดสต๊อก

### 4. 📦 Product & Inventory Module (คลังสินค้า)
*   `/products` 👉 ตารางรายชื่อสินค้าทั้งหมด (แสดงจำนวนสต๊อก)
*   `/products/create` 👉 ฟอร์มเพิ่มสินค้าใหม่ (รวมถึงฟอร์มกรอก JSON Specifications)
*   `/products/edit/:id` 👉 ฟอร์มแก้ไขสินค้าเดิม
*   `/categories` 👉 หน้าจัดการหมวดหมู่สินค้า

### 5. 🤝 Sales & CRM Module (ระบบขาย B2B)
*   `/customers` 👉 ตารางรายชื่อบริษัทลูกค้า และวงเงินเครดิต
*   `/quotations` 👉 รายการใบเสนอราคา (สถานะ: รอลูกค้าตอบรับ)
*   `/quotations/create` 👉 หน้าสร้างใบเสนอราคา (เลือกสินค้า, ใส่ส่วนลด)
*   `/sales-orders` 👉 รายการบิลขาย (สถานะ: รอส่งของ, รอจ่ายเงิน)
*   `/sales-orders/create` 👉 หน้าเปิดบิลขาย (เมื่อเปิดบิลปุ๊บ ระบบจะยิง API ไปตัดสต๊อก)

### 6. 🛒 Purchasing Module (ระบบจัดซื้อ)
*   `/suppliers` 👉 ตารางรายชื่อคู่ค้า / แหล่งรับซื้อ
*   `/purchase-orders` 👉 รายการใบสั่งซื้อที่เราสั่งของไป (สถานะ: รอรับของ)
*   `/purchase-orders/create` 👉 หน้าเปิดใบสั่งซื้อเพื่อส่งให้ Supplier
*   `/purchase-orders/receive/:id` 👉 **หน้าจอสำคัญ:** เวลารถมาส่งของ พนักงานจะมากดหน้านี้เพื่อ "รับของเข้า" (เมื่อกดรับปุ๊บ ระบบจะยิง API ไปเพิ่มสต๊อก)

## 🔄 ตัวอย่างการทำงานข้ามหน้า (Navigation Flow)
1. ฝ่ายขายอยู่ที่หน้า `/customers` คลิกลูกค้า "บริษัท A"
2. กดปุ่ม "สร้างใบเสนอราคา" ระบบจะ Router พาไปที่หน้า `/quotations/create?customerId=xxx`
3. พอกรอกใบเสนอราคาเสร็จ กดบันทึก ระบบ Router จะพากลับมาหน้า `/quotations` พร้อมแสดงแจ้งเตือน (Toast/Snackbar) ว่าสร้างสำเร็จแล้ว
